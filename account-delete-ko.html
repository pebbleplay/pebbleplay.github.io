계정·데이터 삭제

대상 앱: PC방 키우기, 강화의 탑 (안드로이드) · 운영: Pebble Play · 게임은 이름·이메일을 받지 않으며, 계정은 기기에서 자동으로 만들어지는 익명 사용자 번호(Firebase 인증)입니다.

방법 1. 앱에서 (가장 빠름)

게임 실행 › 설정 › 내 데이터 삭제 › 확인. 삭제는 요청한 날부터 15일 뒤에 이뤄집니다. 15일 동안은 순위·길드(연합) 소속이 숨겨지고, 같은 기기에서 게임을 열어 「삭제 취소」를 고르면 되돌릴 수 있습니다.

방법 2. 이 페이지에서 (앱 없이)

앱을 지웠거나 기기를 바꿨어도, 게임 설정 › 내 데이터 삭제 › 삭제 코드 보기에서 받아 둔 삭제 코드(형식 PP-XXXX-XXXX-XXXX)가 있으면 여기서 삭제를 요청할 수 있습니다. 코드는 게임·계정마다 하나이고, 새로 받으면 이전 코드는 쓸 수 없게 됩니다. 코드는 발급 후 24시간 동안, 한 번만 쓸 수 있습니다.

방법 3. 이메일 (코드가 없을 때)

pebbleplay.games@gmail.com 으로 제목 「계정 삭제 요청」, 게임 이름, 닉네임, (알 수 있으면) 게임 설정에 나오는 사용자 번호를 보내 주세요. 다른 사람 계정을 지우지 않도록 본인만 아는 정보를 추가로 물을 수 있습니다. 30일 안에 답변드립니다.

삭제되는 것과 남는 것

삭제닉네임, 점수·순위 기록, 아레나·결투 팀 기록, 게임 안 우편, 길드·연합 데이터, 가게 데이터, 익명 사용자 번호(Firebase 인증 계정, 연결한 구글 계정 식별값 포함), 삭제 코드. 요청 15일 뒤에 이뤄집니다(취소 방법은 방법 1). 같은 계정으로 두 게임을 하신다면 마지막 게임의 데이터까지 지워질 때 로그인 계정도 함께 지워집니다.
보관결제 기록(해시된 구매 토큰·상품·상태): 환불·부정 사용 방지·법정 보관 의무가 필요한 기간(전자상거래법상 최대 5년)만. 이름·이메일과 연결돼 있지 않습니다. 잠깐 쓰는 요청 제한 숫자와 구글 클라우드 서버 로그(구글 보관 설정 따름).
해당 없음구글이 가진 정보(구글 플레이 구매 내역, 애드몹 광고 데이터)는 구글 계정에서 관리하세요.
